# 界面图片来源

两张图片均为黄公望《富春山居图》的公开领域数字图像，来自 Wikimedia Commons。图片已存入应用资源目录，以便离线使用。

- `fuchun-remaining-mountain.jpg`：《剩山图》，浙江省博物馆藏。[原始文件与版权信息](https://commons.wikimedia.org/wiki/File:Dwelling_in_the_Fuchun_Mountains_(first_half).JPG)
- `fuchun-master-wuyong-scroll.jpg`：《无用师卷》，台北故宫博物院藏。[原始文件与版权信息](https://commons.wikimedia.org/wiki/File:Dwelling_in_the_Fuchun_Mountains_(second_half).jpg)
